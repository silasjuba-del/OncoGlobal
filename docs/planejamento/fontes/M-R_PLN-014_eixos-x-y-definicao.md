EIXO X — O QUE / ONDE?
Domínio morfofuncional.

```
SISTEMA
 → órgão/estrutura
    → morfologia
    → função
    → sítio específico
```

Exemplos:

```
HEPÁTICO
├─ Morfológico
│  ├─ massa
│  ├─ infiltração
│  ├─ dilatação biliar
│  └─ efeito de massa
└─ Funcional
   ├─ lesão hepatocelular
   ├─ colestase
   └─ função sintética
```

EIXO Y — O QUE ESTÁ ACONTECENDO AGORA?
Estado clínico:

```
SINAL / SINTOMA / ACHADO
       ↓
novo | antigo | recorrente | piorando | estável
       ↓
causa conhecida?
SIM | NÃO | INCERTA
       ↓
gravidade / risco
       ↓
eletivo | prioritário | urgente | emergência
```

Aqui está o tempo clínico.

Não é literalmente tempo = gravidade; é:

gravidade + risco → prioridade temporal da ação

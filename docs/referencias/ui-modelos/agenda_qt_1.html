Este painel é apoio operacional. A decisão de preparar é da farmácia, que valida estabilidade, dose prescrita, liberação clínica e rotina interna (RDC Anvisa 220/2004). O app apenas sinaliza oportunidades de agrupamento.

Backup dos dados

Os dados ficam salvos só neste navegador. Se o computador for formatado ou os dados limpos, tudo se perde. Faça backup com frequência.
